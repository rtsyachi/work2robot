# 3分デモ台本・絵コンテ｜Work2Robot

**状態：2026-11-07 改訂。提出版は `materials/demo/demo_with_narration.mp4`（169.0秒。導入を7秒に短縮）。ナレーションは AivisSpeech（音声モデル Lux）で全編を合成し、入力作業動画の元の音声は使わない。下の台本のナレーションが最終原稿（各文の時刻・発音の注意は `materials/demo/narration_script_final.md`）。作り方：`tools/demo_video/narration_aivis.py` → `build_demo.py --narrated` → `qa_narrated.py`。映像の成功を保証するものではない。**

## 核になるメッセージ

**人の作業を動画で見せると、Claudeが業務を理解し、必要なロボット構成を仮選定して、そのロボットが仕事をする様子と導入前の課題が見える。**

人の作業動画 → 業務ワークフロー → ロボット構成の仮選定 → 仮想ロボットによる業務実行 → 課題・確認事項。スライドではなく、アプリの実際の画面で見せる。

## 映像で守る条件

- 入力動画は**模擬作業動画（CGアニメーション）**。実写での認識性能や実機の動作保証として説明しない。導入画像はイメージで、アプリの入力ではない（帯に表示）。
- 短縮版は元動画の時刻を表示し、早送り区間は「早送り」と倍率を出す。判断の場面は等速で見せる。入力動画の元の音声（作業者の説明）は提出動画に入れない。
- ナレーションは合成音声（AivisSpeech・Lux、ACML 1.0）。YouTube の説明文に記載する。
- 商品・カゴ車・ロボットの機種は**模擬データ・仮想カタログ**。仕様照合は「仕様上」で、把持力・可動域・干渉・安全性は未検証（画面と帯に表示）。
- Claudeの結果は**保存済みの実際の応答**（ワークフロー `extraction_20261106_190916`、構成の仮選定 `hardware_20261107_010634`）。収録時に API は呼んでいない。
- 3D再生は決定的な実行器の実行結果（トレース）から作ったもので、事前に用意した映像ではない。改善案は仮説として表示する。

## 制作手順（再現）

1. API（8000）と画面（5173）を起動し、`app/frontend` で `node scripts/demo_capture.mjs` → `local_media/demo_build/shots`・`frames` に画面と3D再生のコマを撮る（Claude API は呼ばない）。
2. AivisSpeech Engine（http://127.0.0.1:10101、音声モデル Lux）を起動し、`.venv/Scripts/python -X utf8 tools/demo_video/narration_aivis.py` → `materials/demo/narration/`（場面別・通しの音声、字幕）と `narration_timing.csv`。原稿は `narration_aivis.py` の `FINAL`（この表と同じ文にする）、場面の時刻は `SCENE_TIMES`。1文ごとに複数テイクを合成し、ローカルの文字起こしで原稿に最も近いものを使う。
3. `.venv/Scripts/python -X utf8 tools/demo_video/build_demo.py --narrated` → `materials/demo/demo_with_narration.mp4`（提出版）・`narration_final.srt`・`scene_manifest_narrated.json`。
4. `.venv/Scripts/python -X utf8 tools/demo_video/qa_narrated.py` → 形式・長さ・音量・無音区間の計測と、確認用のコマ一覧。
5. （旧方式・参考）`build_demo.py`（`--narrated` なし）はナレーションなし・作業者の音声ありの版（`demo_no_voiceover.mp4`）を作る。人が収録する場合は `mix_voiceover.py` で重ねる。

## 時間が足りない場合の削減順

**演出（寄り・注目枠）→ S03 の映像 → S05 の消込**を削る。最後まで残すのは**ワークフロー抽出、構成の仮選定と照合、選んだ構成での業務実行、構成による結果の違い、課題・確認事項**。
