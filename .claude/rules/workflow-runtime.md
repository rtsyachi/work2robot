# ワークフロー実行器の実装ルール

- ノード構造・判定・実行ログの正本は `docs/WORKFLOW_SPEC.md`。これ以外に別形式を独自定義しない。
- **ホワイトリストの比較演算子と3値論理**で判定し、`on_unknown`を厳密に処理する。
- 同じグラフバージョン・入力・能力定義なら**同じ実行トレース**を返す。
- 分岐テストには通常・柔らかい荷物・属性不明を含める。分岐ロジックをケースIDにハードコードしない。
- 業務の規則（`job_rules.py`）は、規則を外すと結果が変わること、対応外の規則が「未対応」になることをテストする。
