# 3分デモ受入監査

1. `docs/DEMO.md`と`docs/ACCEPTANCE.md`を確認する。
2. 存在する実コード・テストコマンドを調べ、実際に動かす。未実装のコマンドは実行したことにしない。
3. 通常・例外・不明の3つの入力で、**異なる分岐トレース**になるか調べる。
4. フローチャートのハイライト、ロボット模擬動作、事前チェックが**実行ログから生成**されるか確認する。
5. APIキー・動画素材の権利・イベント前コード流用の有無を確認する。公開やpushは行わない。
6. 各項目を「合格／不合格／未実装／未検証」に分類し、証拠と次の修正3件を日本語で報告する。
